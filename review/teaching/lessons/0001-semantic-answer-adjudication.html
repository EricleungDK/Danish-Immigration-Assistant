Adjudicate packet G without guessing

Your win is a private, exact-bound decision bundle for all 10 answer cases—not a forced pass. A truthful failure or “not evaluable” decision is valid evidence and should never be changed merely to satisfy a threshold.

You must personally read every exact answer and cited evidence item before checking the independent-human attestation. Procedural help is fine; outsourcing the decisions is not.

The review loop

  1. Read the synthetic prompt and the complete generated answer.
  2. Read each expectation literally and inspect the relevant answer text.
  3. Record Passed, Failed, or Not evaluable for every expectation.
  4. For every cited relationship, compare the claim with the cited evidence.
  5. Record Supported or Not supported. Investigate before leaving uncertainty.
  6. Add a private note when a failure or limitation needs explanation.
  7. Move on only after the case shows complete in the navigation.

Decision standards

  • Required fact: pass only if the answer accurately communicates it.
  • Forbidden claim: pass only if the prohibited claim is absent.
  • Privacy: use Not evaluable when the packet lacks the needed runtime or storage evidence.
  • Claim support: supported only if the cited excerpt directly supports that exact claim without an unsupported leap.

Finish safely
